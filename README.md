Base pública de engenharia para pesquisa de faucet em testnet DarkFi. O trabalho atual está concentrado em arquitetura, contratos e modelos reproduzíveis — sem apresentar como operacional algo que ainda está em validação.

```text
Rust / WASM
   ↓
FaucetPool
   ↓
controle de top-up
   ↓
segurança + reprodutibilidade
   ↓
validação em testnet
```

## Sistema pessoal de corpo e mente

O **PULSO 99** organiza conhecimento, práticas e referências em uma interface inspirada nos softwares multimídia de 1999. O sistema conecta alimentação, respiração, biblioteca pessoal e registros em um ambiente único, acessível no navegador.

| Módulo | Função | Acesso |
|:--|:--|:--:|
| **DIETA.DAT** | Atlas alimentar, fichas, comparação e estudo nutricional | [Abrir](https://pulsar99.com.br/alimentos) |
| **RESPIRA.EXE** | Práticas respiratórias e coleção de materiais | [Abrir](https://pulsar99.com.br/respiracao) |
| **BIBLIOTECA** | Livros, vídeos e referências pessoais | [Abrir](https://pulsar99.com.br/biblioteca) |
| **NOTAS.TXT** | Registro público de ideias e observações | [Abrir](https://www.threads.com/@renat0cunha) |

## OKINAVI

O núcleo alimentar do PULSO 99 é o **OKINAVI**, um atlas público que transforma composição nutricional em leitura prática: entrega provável, preparo, moduladores de absorção, sistemas do corpo e lacunas que ainda permanecem.

- [Atlas dos alimentos](https://pulsar99.com.br/alimentos/atlas)
- [Comparador de entrega nutricional](https://pulsar99.com.br/alimentos/comparar)
- [Motor de lacunas](https://pulsar99.com.br/alimentos/lacunas)
- [Atlas Vivo do Corpo](https://pulsar99.com.br/estudo/corpo)

## Princípios

```text
dado bruto -> curadoria -> entrega nutricional -> decisão prática -> aprofundamento
```

- Conteúdo essencial disponível em HTML real.
- Dados quantitativos separados de interpretação.
- Evidência e limitações preservadas nas fichas.
- Experiência responsiva para desktop e dispositivos móveis.
- Nenhuma alegação clínica mais forte do que sua fonte.

## Arquitetura

```text
PULSO 99
|-- Alimentação / OKINAVI
|   |-- Atlas
|   |-- Comparador
|   |-- Motor de lacunas
|   `-- Atlas Vivo do Corpo
|-- Respiração
|-- Biblioteca
`-- Notas
```

O projeto utiliza **Node.js**, renderização inicial no servidor, HTML semântico, CSS e JavaScript nativos. A publicação é realizada continuamente pelo GitHub no Railway.
